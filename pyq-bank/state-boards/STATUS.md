# State-board status for this pass

The repository started state-board work in the requested priority order: CGBSE Chhattisgarh, UPMSP Uttar Pradesh, MSBSHSE Maharashtra, BSEB Bihar, and MPBSE Madhya Pradesh.

The source catalog contains 25 five-subject/year rows per board for 2021–2025. Official URLs were populated only when verified. The extraction pass downloaded 15 official PDFs and produced 935 question chunks. Maharashtra contributed the largest verified paper set; Bihar contributed a verified 2025 five-subject set; CGBSE contributed two official PDFs but both failed during this download attempt because of TLS EOF errors. UPMSP and MPBSE official pages exposed model/sample material but not a verifiable annual five-year archive in this pass.

The repository deliberately distinguishes annual PYQs from model/sample papers. Empty URLs and `official-source-unavailable` rows are preserved as evidence gaps for the next credit refill. The remaining boards are listed in `others-TODO/TODO.md`.
