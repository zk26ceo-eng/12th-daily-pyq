# CGBSE Chhattisgarh

This is an official-source-only starter catalog. The five-year CSV has rows for five main subjects and 2021–2025. A blank `source_url` means the official board archive could not be verified in this pass; it is intentionally not filled with a coaching or aggregator link.

Latest official sample/model-paper page: https://cgbse.nic.in/Documents/2025/parakh/12/020.pdf

Marking scheme or answer-key link: https://cgbse.nic.in/curriculam/2023/12/HR_020_Syllabus_2022_23.pdf

Limitation: Official CGBSE pages exposed two verifiable Class XII PDFs but not a complete named five-subject 2021–2025 catalogue. The marking document is older (2019–20 label).

The full source metadata is in `sources.json`; the question rows are in `questions.csv`. When a PDF is available, add extracted question text and topic labels without changing the source URL.
